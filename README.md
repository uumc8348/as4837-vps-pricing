AS4837 是中国联通的骨干网自治域，买“4837 VPS”看中的就是回程从美国机房走联通骨干回国。它和联通另一条精品线路 AS9929 同属联通体系，价格更低，稳定性和负载表现相差不大，所以这两年成了 9929 之外最主流的“大陆优化”选项。

## 回程实测：所谓“三网4837”实际怎么走

走。第三方测评的 traceroute 显示，联通三个方向回程全程落在 AS4837，电信和移动大部分方向也走 4837，个别方向存在替代路径。这比宣传页上笼统一句“三网 4837”信息量大得多。

拆开看各个方向：

- **联通**：北京、上海、广州回程全部走 AS4837
- **电信**：上海、广州方向走 AS4837 回国；北京方向从电信与 level3 在洛杉矶的互联点直连回国
- **移动**：北京、广州方向走 AS4837；上海方向先走 AS4837 到香港，再从移动香港节点回内地
- **去程**：三家各自直连美国节点（电信圣何塞、联通圣何塞、移动洛杉矶），再接 Cogent 进洛杉矶机房
